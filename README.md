# Life-Expectancy-Analysis


Data Source: [Life Expectancy Dataset – Kaggle](https://www.kaggle.com/datasets/nailasrivastava/life-expectancy-analysis)

This project is currently work in progress, but several steps have already been completed:

### Project Structure
LED.ipynb – Initial data exploration and preprocessing.

Cleaned_Life_Expectancy.csv – Dataset with missing values removed.

fixing.ipynb – Notebook containing functions to detect and correct anomalies in the dataset, including scale corrections for Population, GDP, Alcohol, Thinness, and Vaccine percentages.

LE.twb – Tableau workbook containing two interactive dashboards.

Through these dashboards, it became clear that simply removing N/A values was not sufficient. Work is now focused on detecting and correcting anomalies in the data, which will improve the quality and reliability of visualizations.

-	Online Dashboard Link: [View on Tableau Public](https://public.tableau.com/app/profile/roman.larkin/viz/LE_17562775085450/Dashboard2?publish=yes)

### Next Steps
-	Improve data quality by detecting and correcting anomalies.
-	Update Tableau dashboards with cleaned data.
-	Add further analysis on trends and correlations in life expectancy.
